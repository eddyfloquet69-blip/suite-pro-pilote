# Suite Pro — Landing page publique (prototype / pilote)

Cette version comprend uniquement la page de présentation `index.html` : **pas de code source SaaS**, pas de base de données, aucun suivi externe et aucune connexion client. Le bouton principal ouvre un email, et le calculateur est une simulation en JavaScript locale.

Pour publier sur GitHub Pages :
1. Dépôt créé : `eddyfloquet69-blip/suite-pro-pilote`.
2. Page HTML ajoutée dans la branche `main` via le connecteur GitHub.
3. Dans Settings → Pages → Build and deployment, sélectionner Deploy from a branch, branche `main`, dossier `/ (root)`, puis Save.
4. Lire l'URL réellement fournie dans GitHub Pages et vérifier sur mobile et desktop.

Avant diffusion large, vérifier la disponibilité du nom et les obligations de mentions légales et informations sur le traitement des emails de prospects. Aucune promesse d'économie ni de disponibilité du SaaS en production.
